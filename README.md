# UWU-Firmware-2.0

## Overview

The Firmware for the Typeuwu v2 and Macruwu v3.

---

## Folder Structure

| Item | Description |
| ------ | ------------- |
| `.platformio/` | Scripts and config used by PlatformIO |
| `boards/` | Custom board definition for the RP_Moduluwu board |
| `example_config/` | Example Animacro config |
| `include/` | Header files |
| `lib/` | Third-party libraries and the UWU-Lib submodule |
| `src/` | Source files |
| `test/` | Test files and directories (unused. We test in production...) |
| `variants/` | PlatformIO environment configuration for the RP_Moduluwu |
| `.clang-format` | Clang formatting rules |
| `.clang-tidy` | Clang-tidy  rules |
| `platformio.ini` | PlatformIO configuration - defines build environments, dependencies, and build flags |
| `pre_setup_uwu_lib.py` | Pre-build hook script - initializes/syncs UWU-Lib submodule before every build |
| `regenerate_compile_commands.sh` | Helper script - detects active environment from `.vscode/c_cpp_properties.json` and regenerates `compile_commands.json` for clangd |

## Build Instructions

### Getting Started

UWU-Lib is shared via Git submodule and auto-managed during builds.

**First-time setup:**

```bash
# Clone and initialize submodules
git clone <repository-url>
cd UWU-Firmware-2.0
git pull

# Build your firmware (automatically initializes submodule)
pio run -e macruwu3    # or
pio run -e typeuwu2
```

> [!NOTE]
> The script `pre_setup_uwu_lib.py` is automatically executed on build and will automatically initialize and sync UWU-Lib if needed.

### Updating UWU-Lib

When you pull updates from the main repository, the submodule will automatically sync to the version defined in `.gitmodules` during the build process.

If you need to update to a newer version:

```bash
git submodule update --remote lib/UWU-Lib
```

After updating, rebuild your firmware:

```bash
pio run -e <environment>
```

The pre-build script will automatically sync the submodule if needed.

### Regenerating compile_commands.json

Clangd requires a separate `compile_commands.json` for each environment:

```bash
# Using the helper script (recommended)
./regenerate_compile_commands.sh

# Or manually
pio run -t compiledb -e macruwu3
pio run -t compiledb -e typeuwu2
```

### Switching Environments

Use the PlatformIO environment selector in VS Code (status bar) to switch between `macruwu3` and `typeuwu2`.

> [!NOTE]
> If using clangd, regenerate the `compile_commands.json` when switching environments.

## CLANG & IDE SETUP

PlatformIO, by default, uses the Microsoft C/C++ extension as a linter. Alternatively this project provides support for clangd.
However, due to lack of a better option, the `c_cpp_properties.json` generated by the Microsoft C/C++ extension is used to determine the active environment. The `regenerate_compile_commands.sh` script reads this file to detect the current environment and generates the appropriate `compile_commands.json` for clangd.

**Workflow:**

1. Switch environment in VS Code (status bar)
2. Regenerate `compile_commands.json`:

   ```bash
   ./regenerate_compile_commands.sh
   ```

3. Clangd will auto-detect and update IntelliSense

> [!NOTE]
> If Clangd does not auto-update, it may need to be reloaded with `CTRL+SHIFT+P` -> select 'clangd: restart language server'

## FS Notes

Find the drive with:

```bash
lsblk
```

Then format it as FAT12:

```bash
sudo mkfs.fat -v -F 12 -S 512 -n YOUR_LABEL /dev/YOUR_DRIVE
```

Optionally set/change the name later:

```bash
sudo dosfslabel /dev/YOUR_DRIVE YOUR_LABEL
```

If formatting fails, use `flash_nuke.uf2` to reset the flash to factory settings, then reflash and try again.
